🎨 UI Design Rules
Background

Don't use pure #000000.

Use:

#07080D

Then use very subtle gradients:

Violet → transparent

and

Cyan → transparent

Cards

Use:

#11131C

with approximately 10–15% transparency.

Border:

1px subtle violet/cyan

Buttons

Primary:

Electric Violet

Secondary:

Transparent + thin cyan border

Use rounded corners around 12–16px, not giant pill buttons everywhere.

✨ Animation System

Keep animations smooth and premium:

Button tap
→ tiny scale-down

Tournament card
→ subtle glow on touch

Rank increase
→ XP animation

Win
→ particle burst

Loading
→ rotating neon ring

Page transition
→ 200–300ms slide/fade

Don't overuse animation. Premium ≠ maximum effects.
